# TAGE branch predictor in ChampSim

Course project P14, Advanced Computer Architecture (IIIT Hyderabad), by Arya Mirani.

Implementing a simplified TAGE predictor (a bimodal base plus 4 partially tagged tables) in ChampSim
and comparing it with bimodal and gshare on SPEC CPU2017 traces.

`./setup.sh` clones ChampSim at the pinned commit and links `predictors/` into it.
